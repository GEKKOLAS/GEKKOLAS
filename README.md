## About me

I'm **Nicolas Murillo** (`@GEKKOLAS`), a full stack developer with a strong focus on **C# / .NET**, modern web applications, APIs, and architecture-minded engineering.

I enjoy moving between **backend systems**, **frontend experiences**, and **product decisions**—from modelling business workflows and designing data boundaries to delivering polished applications. My background also spans **international business, digital marketing, and data analysis**, which helps me connect engineering choices to practical outcomes.

- **I build:** business applications, REST APIs, distributed services, dashboards, and workflow automation.
- **I value:** clean architecture, explicit domain modelling, maintainability, testing, and clear collaboration.
- **I work across:** .NET, Angular, React / Next.js, SQL and NoSQL, cloud infrastructure, and delivery tooling.
- **I explore:** system design, modern developer workflows, automation, and AI integrations.

> **My engineering philosophy:** build software that is understandable, useful, and resilient—not just impressive in a demo.
